What does this prove?

Sequential: Five waits happen one after another, taking at least ~5 seconds.

Async: asyncio.gather() overlaps non-blocking waits and HTTP requests.

Threads: A thread pool overlaps blocking waits and HTTP requests using multiple threads.

Both async and threads can finish near ~1 second plus network overhead. Exact times vary. The webpage's JavaScript fetch() only calls your Python backend; the concurrency experiment happens in Python.
